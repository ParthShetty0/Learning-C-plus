# Number Guessing Game (C++)

A lightweight, console-based number guessing game developed in C++.

## Features & Functionality

* **Random Number Generation:** Automatically generates a pseudo-random secret number within a predefined range (e.g., 1 to 100) on each run.
* **Interactive User Input:** Prompts the player to guess the secret number via the standard terminal/console.
* **Smart Feedback System:** Provides immediate real-time hints after each attempt:
  * Alerts if the guess is **Too High**.
  * Alerts if the guess is **Too Low**.
* **Attempt Tracking:** Keeps count of the total number of attempts taken to find the correct number.
* **Win State & Summary:** Detects when the correct number is guessed and displays a victory message along with total attempts used.
* **Input Validation:** Handles basic numeric input flow gracefully within the console loop.
