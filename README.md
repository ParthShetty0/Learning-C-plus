# C++ Fundamentals & Practice Repository

A hands-on collection of beginner-to-intermediate C++ programs, exercises, and mini-projects created to build a strong foundation in modern C++ programming and computer science principles.

---

## 🎯 What This Repository Is About

This repository serves as a centralized log of my journey learning C++. It contains solutions, practice scripts, and foundational projects focused on applying theoretical concepts to real, working code.

### Core Focus Areas
* **Language Basics:** Syntax, control structures, loops, functions, and standard input/output.
* **Data Structures & Memory:** Pointers, references, arrays, dynamic memory allocation, and basic STL containers (`vector`, `string`, `map`).
* **Object-Oriented Programming:** Classes, objects, encapsulation, inheritance, polymorphism, and abstraction.
* **File Handling & Logic:** Working with file streams (`fstream`), basic data persistence, and problem-solving through console-based applications.

---

## 🛠️ Tech Stack & Requirements

* **Language:** C++ (C++17 or later)
* **Compiler:** `g++`, `clang++`
* **Build/Run:** Standard command-line compilation
