       SIMPLE C++ CONSOLE CALCULATOR
========================================

1. DESCRIPTION
--------------
A basic, minimal command-line calculator written in C++. It prompts the user for an arithmetic operator (+, -, *, /) and two numbers, then computes and displays the result using a switch-case statement.

2. FEATURES
-----------
- Supports 4 basic operations:
  * Addition (+)
  * Subtraction (-)
  * Multiplication (*)
  * Division (/)
- Floating-point support (double precision)
- Input validation message for invalid operators

3. REQUIREMENTS
---------------
- C++ compiler (g++, clang++, or MSVC) supporting C++11 or later

4. HOW TO COMPILE & RUN
-----------------------
Using GCC (g++):

  1. Compile:
     g++ calculator.cpp -o calculator

  2. Run:
     ./calculator        (Linux/macOS)
     calculator.exe      (Windows)

5. EXAMPLE USAGE
----------------
*********** CALCULATOR ***********
Enter the operator (+ - * /): *
Enter a Number : 12.5
Enter Second Number : 4
Result : 50
